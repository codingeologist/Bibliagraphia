Bibliagraphia

A Bible graph in a single DuckDB file — source

The Bible is stored as a property graph in one DuckDB file. Everything is a node of one of five types (labels), connected by three kinds of edges:

  • book identified by a 3-letter book code (GEN, JOH, REV) or its full name
  • verse one verse of one Bible version, e.g. Genesis 1:1 (KJV)
  • version a Bible translation, identified by a 3-letter version code: KJV, VUL, DRB
  • region a broad geographic area, e.g. Syria
  • location a place mentioned in a verse, e.g. Jerusalem
  • verse_in_book — book → its verses
  • verse_in_version — version → the verses it contains
  • location_in_region — location → the region it lies in

Typical queries:

  • Search to find a node by name — then click a result to load it into one of the tools below automatically.
  • Traverse walks down one edge type from a start node, e.g. start at Genesis (book) via verse_in_book to list its verses. Books pair with verse_in_book, regions with location_in_region, versions with verse_in_version.
  • Shortest path finds how two nodes connect through the graph (up to 10 hops), e.g. John → Syria.
  • Cross-version verse shows the same verse side by side in every loaded version. Book codes are three-letter OSIS abbreviations, e.g. GEN, JOH, MAT.
  • Graph explorer draws the neighborhood around a node (1–3 hops) as an interactive force-directed graph — the full database is too large to draw at once. Click any node in the drawing to re-center there.
  • Map plots location mentions on a Roman Empire-era basemap, scoped by region or by book. Every location in the database is geocoded.

Search

Look up any node by name or code — book codes (GEN, JOH), version codes (KJV, DRB), places (Jerusalem), regions (Syria). Codes are unique 3-letter identifiers. Click a result to load it into the tools below.

    Traverse (descendants along an edge)

    Follow one edge type downward from a start node: books → verses (verse_in_book), versions → verses (verse_in_version), regions → locations (location_in_region). Start by book code (JOH) or version code (KJV) — names also work. Example: start GEN, label book, edge verse_in_book.

      Shortest path (verse → region)

      Find the chain of edges linking two nodes through the graph (e.g. verse → book → verse → location → region). Enter a book/version code (JOH, KJV) or a full name — regions and locations have no codes, so use names for them (Syria, Jerusalem). Easiest workflow: run Search first, then click a result to fill in this tool automatically.

      →

        Graph explorer (force-directed)

        Draw the neighborhood around a node as a force-directed graph. Pick a start node (code or name — e.g. JOH, DRB, Syria) and how many hops to include. Interactions: drag empty space to pan, scroll to zoom, hover a node to see its name, click a node to re-center the graph there.

        Map of locations

        Plot location mentions on a map of the Roman Empire world. Scope by region (all places located in e.g. Syria) or by book (all places that book mentions, e.g. JOH). Each dot is one verse-mention — click it to see the reference and KJV text. Basemap: Esri World Imagery satellite

        Cross-version verse

        Compare one verse in every loaded Bible version. Use the three-letter book code (JOH = John, GEN = Genesis), plus chapter and verse numbers. Example: JOH 3 16.
